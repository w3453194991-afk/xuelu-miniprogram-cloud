## 演示路径

### 多日期家教预约与搜索

家教详情点击预约，选择实际日期后查询开放时段，添加一个或多个日期的课次（每个时段1小时，每单最多20个），金额由服务器按单价和课次数计算。开放时段沿用后台配置的中文星期，如“周六 09:00–10:00”。当前是模拟交易，不是教师真实接单确认。

订单和个人中心展示课次日期；个人中心提供按日期排序的预约日程。旧版单时段订单继续兼容。完成仍为整单完成，不提供单课次签到或部分退款。

搜索历史只保存在当前浏览器，最多10条，可点击复用、逐条删除或清空。家教列表支持按已录入学校、教学科目和授课方式筛选，身份/性别和年级学科联动尚未实现。

### 深化后的管理入口

在管理工作台中选择“机构管理 / 家教管理 / 校车管理”，点击“发布服务”或已有服务的“编辑”。三类表单独立维护业务资料：

- 机构：授课地址、机构联系人、电话、介绍、师资（每行一条）。
- 家教：学校、学历、科目、授课方式、适教年级、经验、可预约时段（每行一条，每次1小时）。时段仍是固定周末演示，不代表真实日期排期。
- 校车：驾驶员、电话、车牌、车辆、月付套餐、2–20个线路站点与到达/出发时刻。

保存后用户端详情与报名表读取相应配置。校车报名下车点只显示上车点之后的站点。公开管理模式下仅填写虚拟资料。

1. 首页选择课程、家教或校车，点击查看详情。
2. 输入演示姓名和手机号 `13800000000`，提交订单。
3. 在“我的订单”进行模拟支付，获取核销码。
4. 切换“管理工作台”，核销并完成订单。
5. “我要入驻”提交申请，在管理工作台通过审核。

## 架构

- `public/`：响应式网页，含家长端与演示管理工作台。
- `server.mjs`：独立 HTTP JSON API，后续可供小程序调用。
- `data/store.json`：首次启动生成，保存订单和入驻申请，重启不丢失。
- `tests/api.test.mjs`：接口集成测试，独立临时数据库，不污染演示数据。

运行测试：`node --test tests/api.test.mjs`。

### 核心接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | /api/services | 服务目录 |
| GET / POST | /api/orders | 查看 / 创建订单 |
| POST | /api/orders/:id/pay | 模拟支付 |
| POST | /api/orders/:id/cancel | 取消待支付订单 |
| POST | /api/orders/:id/complete | 核销已支付订单 |
| GET / POST | /api/applications | 查看 / 提交入驻申请 |
| POST | /api/applications/:id/approve | 审核通过 |

价格由服务器决定；支付时串行检查名额和家教时段冲突，防止同进程重复出售。此机制仅面向单进程演示，不支持多实例部署。

## 演示边界与后续工作

当前不是可公网运营的生产系统。服务器仅监听本机；无登录、商家隔离、真实支付、真实定位、实际资质审核、退款或真实通知。所有访问共享一个演示账号，管理员页面和接口不设权限，核销由管理员点击完成，不校验输入核销码。不要输入真实学生信息、证件或部署到公网。当前家教使用固定周末时段，没有实际日期与排课日历；校车为固定月套餐；课程为订单级核销。

入驻审批目前只更改申请状态，不创建商家账号或发布服务。服务目录是服务器内置演示数据。网页端使用系统 emoji 插画，字体加载失败会回退系统字体。

上线前：接入数据库事务、认证与多商家权限、隐私保护、正式日期排期、支付及退款、库存超时释放、日志备份与安全测试。小程序尚未实现，将复用 API 和订单状态模型；微信合法域名与 HTTPS 在上线阶段配置。
