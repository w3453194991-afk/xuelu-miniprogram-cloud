# legacy-amap · 旧版高德地图模块（存档）

本目录来自网页端早期快照（2026-10-24），**当前 `web/public/` 已不引用其中任何文件**。

| 文件 | 说明 |
| --- | --- |
| `map.js` | 高德地图组件封装（AMap JS API 2.0 + Geocoder / ToolBar 插件），含实例销毁逻辑 |
| `map-test.html` | 该组件的独立调试页 |
| `AMAP_SETUP.md` | 高德 Key 申请与接入步骤 |
| `verify-map.mjs` | 地图配置校验脚本 |

保留原因：后续 2026-11-01 版本移除了地图相关代码（`web/public/` 中已无 `AMap` / `leaflet` 引用），
但小程序端仍有校车路线、机构地址等地理信息展示需求。若需要恢复地图能力，可从本目录取回参考实现，
或参考 `学鹭-网页版.zip` 单文件构建产物中内联的 Leaflet 方案。

> 注意：这些文件依赖外部高德 SDK 与自备 Key，直接启用前需重新申请并在 `AMAP_SETUP.md` 所述位置配置。
