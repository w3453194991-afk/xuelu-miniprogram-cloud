# 学鹭伴学 - 部署说明

这个文件夹包含部署到服务器所需的全部文件。

## 📁 文件清单

- `index.html` - 主页面（橙色深色版）
- `README.md` - 本说明文件

## 🚀 部署方式

### 方式 1：GitHub Pages（免费）

1. 在 GitHub 创建新仓库
2. 将本文件夹内所有文件上传到仓库
3. 进入仓库 Settings → Pages
4. Source 选择 `main` 分支，目录选 `/`（根目录）
5. 点击 Save，等待几分钟后访问提供的网址

### 方式 2：Vercel（免费，推荐）

1. 访问 [vercel.com](https://vercel.com)
2. 注册并登录
3. 点击 "New Project"
4. 上传本文件夹，或连接 GitHub 仓库
5. 点击 Deploy，几秒钟后即可访问

### 方式 3：Netlify（免费）

1. 访问 [netlify.com](https://www.netlify.com)
2. 注册并登录
3. 拖拽本文件夹到 Netlify 的上传区域
4. 等待部署完成，会自动生成网址

### 方式 4：自己的服务器

如果你有 Nginx / Apache 服务器：

1. 将 `index.html` 上传到网站根目录（通常是 `/var/www/html` 或 `/usr/share/nginx/html`）
2. 确保文件权限正确：`chmod 644 index.html`
3. 访问你的域名即可

如果用的是虚拟主机/空间：
1. 通过 FTP 或面板上传 `index.html`
2. 确保文件名是 `index.html`（有些主机需要 `index.htm`）
3. 访问你的域名

## 📱 功能说明

- ✅ 完全离线可用，无需数据库或后端
- ✅ 响应式设计，手机和桌面端都可正常访问
- ✅ 数据保存在浏览器本地（LocalStorage）
- ✅ 支持搜索、筛选、查看详情、保存意向

## ⚠️ 注意事项

1. **这是演示页面**，所有服务数据都是硬编码在代码里的演示内容
2. 用户保存的"预约意向"只存在浏览器本地，不会提交到服务器
3. 如果需要接入真实业务，需要后端 API 和数据库支持

## 🎨 定制修改

如果你需要修改内容（比如更换演示数据、调整文案）：

1. 用文本编辑器打开 `index.html`
2. 找到 `const services=[` 这一行（大约在第 6 行）
3. 修改里面的数据
4. 保存后重新上传即可
